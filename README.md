# 🎨 Sayali Pagare — Minimalist Bento Portfolio

[![Vercel Deployment](https://img.shields.io/badge/Deployed%20on-Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://vercel.com)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)

A clean, modern, single-page portfolio website built using a **Bento Grid** visual framework. Designed to highlight UI/UX case studies, frontend builds, academic milestones, and leadership experience with dark and light theme switching.

---

## ✨ Features

- **🍱 Bento Box Layout**: Modular grid architecture optimized for desktop and mobile responsiveness.
- **🌗 Theme Toggle**: Smooth transition between Dark and Light mode.
- **📂 Project Showcases**: Dedicated sections for code builds and Figma UI/UX case studies.
- **⚡ Responsive Grid**: Adapts dynamically from single-column mobile views to 4-card row layouts on desktop.
- **⚡ Zero Build Setup**: Runs directly via CDN scripts (Tailwind CSS & Font Awesome).

---

## 🛠️ Tech Stack

- **Markup & Styling**: HTML5, [Tailwind CSS CDN](https://tailwindcss.com/)
- **Typography**: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) (Display), [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Body), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (Code/Labels)
- **Icons**: Font Awesome 6.5.1
- **Deployment**: [Vercel](https://vercel.com/)
